TESOURO SECURITY WEBSITE
========================
Static multi-page corporate website.

Pages:
- index.html (home, linked as /)
- about.html (linked as about)
- services.html (linked as services)
- policies.html (linked as policies)
- contact.html (linked as contact)

Deployment:
- .nojekyll included for GitHub Pages.
- 404.html provides extensionless route fallback on GitHub Pages.
- Replace SVG/JPG files inside /images with your own photography if desired.
- Keep filenames the same to update images without editing HTML.

Contact form:
This is a static website, so the form opens the visitor's email client addressed to
enquiries@tesourosecurity.co.uk. For server-side form submission, connect the form
to your hosting provider or form endpoint.

Important:
Policy PDFs are professionally formatted templates. Review them against actual
company operations and legal requirements before formal adoption/publication.
